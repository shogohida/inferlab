inferlab — LLM inference engine, from scratch— LLM推論エンジン自作

A from-scratch transformer inference engine in pure Go: the forward pass, a KV cache, int8 weight-only quantization, and decode-only continuous batching, all implemented without any ML library. Generate text live below, then run the benchmark to see exactly what each optimization buys — and costs.

Go言語のみでゼロから実装したTransformer推論エンジン（外部MLライブラリ不使用）。フォワードパス・KVキャッシュ・int8量子化・デコード時のみのcontinuous batchingを実装。下でテキスト生成を試し、ベンチマークで各最適化が実際にどれだけ効くのか（そして何を犠牲にするのか）を確認できます。

Generateテキスト生成

The model is stories15M (Andrej Karpathy's llama2.c project, trained on the TinyStories dataset) — a Llama-2-architecture model small enough to run token-by-token on a free-tier CPU. It only knows simple children's-story vocabulary; that's expected.モデルはstories15M（Andrej Karpathy氏のllama2.cプロジェクト、TinyStoriesデータセットで学習）— 無料枠のCPUでも1トークンずつ実行できる小型のLlama-2アーキテクチャモデルです。語彙は簡単な童話レベルに限られますが、それは想定通りです。

Benchmarkベンチマーク

Runs the same prompt under five configurations and measures real tokens/sec — no cache, KV cache, KV cache + int8, and batch size 1 vs 3 concurrent sequences.同じプロンプトを5種類の設定で実行し、実測のtokens/secを計測します — キャッシュなし、KVキャッシュあり、KVキャッシュ+int8、そしてバッチサイズ1 vs 3並列。
